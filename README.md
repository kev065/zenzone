# ZenZone Chatbot: Your Personal Wellness Companion

ZenZone is a compassionate AI chatbot designed to provide personalized support and guidance for your mental and emotional well-being. It leverages the power of OpenAI's advanced language models to offer empathetic conversations, practical advice, and evidence-based information.

## Key Features

- Personalized Support: Tailored responses based on your unique needs and emotions.
- Empathetic Listening: Active listening and understanding of your feelings.
- Practical Advice: Offers actionable tips and strategies for self-care.
- Evidence-Based Information: Access to reliable health information when needed.
- Private and Secure: Your conversations are kept confidential.

## Getting Started

1. Clone the Repository:

    ```
    git clone git@github.com:kev065/zenzone.git
    cd zenzone
    ```

2. Install required dependencies:

    ```pip install -r requirements.txt```

3. Create a .env file and set up API keys for Langchain, OpenAI and Tavily:

    ```
    TAVILY_API_KEY=your_tavily_api_key
    LANGCHAIN_API_KEY=your_langchain_api_key
    OPENAI_API_KEY=your_openai_api_key
    ```

4. Run the App:

    ```
    streamlit run main.py
    ```

5. Contributing:

We welcome contributions to improve ZenZone! Feel free to fork the repository, make changes, and submit a pull request.
